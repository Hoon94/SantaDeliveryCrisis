🎅 산타의 작업실 탈출 · 디자인 시안 v0.2

기획서와 와이어프레임 이후에 바뀐 규칙(작업 4개, 장식 12칸, 세션 단위 보상, 애니메이션 문제 등)을 반영한 시안입니다. 색상과 분위기는 기존 시안 A를 그대로 쓰고, 그림은 이모지·SVG 임시 그림입니다. 실제 제작 단계에서 일러스트로 교체합니다. 기준 문서는 .kiro/steering/project-spec.md입니다.

기존 시안(index.html A)에서 바뀐 점

  • 탭이 4개(방·출제·기록·관리)에서 3개(작업·기록·관리)로 줄었습니다. "출제" 탭은 작업 화면의 "오늘의 출제" 버튼(4개 작업을 섞어 앱이 구성)으로 들어갔습니다.
  • "방" 대신 작업 4개(소원 접수·선물 생산·포장·썰매 적재)를 고릅니다. 각각 AI 활용, Swift 문법, HIG, SwiftUI 실전 카테고리에 대응합니다.
  • 열쇠가 없어지고, 트리 장식 12칸을 모두 채우면 산타가 선물 배달을 떠납니다.
  • 장식은 문제마다가 아니라 세션이 끝난 뒤(정답률 기준 이상일 때) 난이도별 1·2·3개를 받습니다.
  • 세션 시작 전에 난이도, 태그(선택), 문제 수(5·10·15)를 고릅니다. 문제 수가 부족한 선택지는 잠깁니다.
  • 코드 실행을 줄별로 보여 주는 애니메이션 문제가 추가됐습니다. 건너뛰기·다시 보기는 1차에 없습니다.
  • 완성한 트리는 보관함에 쌓이고, 기록 화면에서 완성 횟수를 볼 수 있습니다.
  • 기본 제공(시드) 문제는 수정·삭제 버튼이 보이지만 비활성화됩니다.
  • iPad는 목록과 상세가 나뉜 분할 화면으로 확장합니다.
  • 6장에 상태 화면(진행 중 세션이 있을 때의 선택, 조건에 맞는 문제가 없을 때, 오답이 없을 때)을 추가했습니다.

1. 작업 탭

트리를 꾸미고 작업을 골라 세션을 시작하는 화면들

2. 퀴즈 진행

일반 문제와 애니메이션 문제. 보기를 눌러 선택하고 [확인]을 누르면 채점됩니다. (이 시안에서도 직접 눌러 볼 수 있어요)

3. 세션 결과

장식은 이 화면에서 받습니다. 트리가 완성되면 산타가 출발하는 연출이 이어집니다.

4. 기록 · 관리 탭

통계 확인, 문제 관리, 설정

5. iPad

가로·세로를 모두 지원합니다. 작업 선택(S2)과 문제 관리(S10)는 왼쪽 목록, 오른쪽 상세의 분할 화면으로 확장합니다.

6. 상태 화면

진행 중 세션이 있을 때의 선택, 조건에 맞는 문제가 없을 때, 오답이 없을 때의 안내 화면
