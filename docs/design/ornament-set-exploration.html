01 · 쉬움도 완성된 장식

작고 단순해도 또렷하고 예쁘게. 쉬움 장식을 미완성품처럼 표현하지 않습니다.

02 · 어려울수록 더 섬세하게

난이도는 문양·소재·실루엣으로도 구분합니다. 효과를 꺼도 차이가 남습니다.

03 · 획득은 화려하게, 트리는 차분하게

획득 효과는 상세에서 재생합니다. 트리에서는 간헐적인 작은 반짝임만 더합니다.

장식 형태를 선택하기 위한 HTML 디자인 시안입니다. 앱의 보상·해금 규칙이나 저장 데이터는 변경하지 않습니다. 후보는 이 페이지를 열어 둔 동안만 유지됩니다. 기본 트리의 정상 별은 배경 이미지에 포함되어 있으며 수집 장식 12개와 별개입니다.
