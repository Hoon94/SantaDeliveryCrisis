# 작업 1. 시드 데이터

- 상위 문서: [프로젝트 스펙](../../.kiro/steering/project-spec.md). 이 문서에서 말하는 5장, 8장, 9장, 11장은 그 문서의 장입니다. 데이터 모델(8장)과 모듈 인터페이스(9장)는 모든 작업이 맞춰야 하는 공통 계약이라 그쪽에 있습니다.
- 통합 완료 조건과 확인 담당: [통합 계약표](../integration-contracts.md)
- 표기: `[가정]`은 팀이 아직 확정하지 않은 내용입니다. 구현 전에 사용자에게 확인합니다(프로젝트 스펙 16장).

## 작업 범위

- 포함: 시드 JSON 스키마, 로더, 첫 실행 주입, 문제 작성(60문제 이상)
- 의존: 0
- 병렬 가능: 문제 작성은 작업 0 중에도 시작 가능

## 시드 데이터
- 앱 번들의 JSON 파일(`Seed/questions.json`)을 첫 실행 때 SwiftData에 넣습니다. 같은 `id`가 이미 있으면 건너뜁니다.
- JSON 필드는 `Question` 모델 필드와 이름을 같게 맞춥니다. 이미지와 영상은 번들 에셋 파일명을 씁니다.
- 분량: 작업 4개 × 난이도 3개 × 구간당 최소 5문제 = **60문제 이상**
- 문제 작성은 팀원이 나눠서 하고, 한 구간의 형식이 통일되도록 작성 가이드(해설 길이, 보기 개수, 태그 규칙)를 `docs/question-guide.md`에 정합니다.
