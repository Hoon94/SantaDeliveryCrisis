## 작업 범위

- 포함: `QuestionSelector`, `SessionManager`, 보상 계산, `TreeManager`, 단위 테스트

## 출제 (`QuestionSelector`)

세션은 출제 탭에서 켜진 장식을 눌러 시작합니다. 장식은 문제 카테고리와 연동하지 않으므로, 후보는 사용자가 고른 카테고리 전체와 선택한 난이도의 문제입니다. 카테고리가 여러 개이면 문제 수를 카테고리 수로 나눠 고르게 배정하고(5문제 4카테고리는 2·1·1·1, 10문제 3카테고리는 4·3·3), 남는 문제는 무작위로 고른 카테고리에 한 문제씩 더 줍니다. 한 카테고리의 후보가 모자라면 다른 카테고리의 남은 후보로 채웁니다. 각 카테고리 안에서는 아래 범주 규칙으로 고르고, 마지막에 순서를 섞습니다. 이 규칙은 `QuestionSelecting.select(categories:...)`와 `availableCount(categories:...)`(둘 다 프로토콜 확장)에 있고, 세션은 `SessionManaging.startSession(categories:...)`로 시작합니다. 카테고리가 하나면 `QuizSession.category`는 그 카테고리, 둘 이상이면 `nil`입니다. 태그 선택은 1차에 없으므로 `tags`는 항상 빈 집합이고, 비어 있으면 전체 태그가 대상입니다(값이 있으면 하나라도 가진 문제). 작업실의 별도 "오늘의 출제"(약한 문제·선호 카테고리 비율로 4개 작업을 섞는 세션)는 1차에 하지 않습니다([future-work](../future-work.md)).

**범주 비율 `[가정]`**

| 비율 | 범주 |
| --- | --- |
| 50% | 약한 문제: 최근 오답이거나 정답률이 낮은 문제 |
| 50% | 오래 안 푼 문제 또는 한 번도 안 푼 문제 |

- 범주별 문제 수는 비율대로 계산해 내림하고, 남는 자리는 약한 문제 범주부터 채웁니다. 5문제는 3·2, 10문제는 5·5, 15문제는 8·7입니다.
- 한 문제가 두 범주에 해당하면 약한 문제를 먼저 배정하고, 한 번 뽑힌 문제는 다른 범주 후보에서 뺍니다. 중복 출제는 없습니다.
- 한 범주에서 후보가 모자라면 다른 범주에서 채웁니다. 두 범주를 모두 쓰고도 모자라면 같은 필터 안의 남은 후보에서 중복 없이 무작위로 채웁니다.
- 후보가 요청한 문제 수보다 적으면 가능한 만큼만 출제합니다 `[가정]`. 후보가 0개일 때만 `startSession`이 오류를 던집니다(S2-B는 고른 카테고리 전체의 후보 합(`availableCount(categories:...)`)이 문제 수보다 적으면 장식을 꺼서 미리 막습니다).
- "정답률이 낮은 문제"와 "오래 안 푼 문제"의 기준값, 범주 안의 선택과 동률 처리는 작업 2 담당자가 정하고 문서화 주석에 적습니다.
- 기록이 없는 새 사용자는 모든 문제를 "한 번도 안 푼 문제"로 보고 무작위로 고릅니다.
- 정해진 문제 수에서 순서는 무작위로 섞습니다.

## 카테고리 추천 (`TaskRecommending`) `[가정]`

출제 팝업(S2)의 [추천] 배지에 씁니다. 답을 한 기록이 있는 카테고리 중 정답률이 가장 낮은 카테고리 하나를 돌려줍니다. 정답률이 같으면 작업 순서(소원 접수, 선물 생산, 포장, 썰매 적재)에서 앞선 카테고리이고, 기록이 전혀 없으면 `nil`입니다. 카테고리는 답한 문제의 스냅샷(`QuestionSnapshot.category`) 기준입니다. 화면은 `nil`이면 배지를 표시하지 않습니다.

## 이어서 풀기
- 문제 하나에 답하고 [확인]을 누를 때마다 세션 상태를 SwiftData에 저장합니다.
- 앱을 시작할 때 `inProgress` 상태 세션이 있으면 S1(작업실)에 "이어서 풀기" 카드를 보여 줍니다.
- 복원 위치는 저장된 답의 수(`answers.count`)번째 문제입니다. `currentIndex`는 답을 저장하는 같은 저장에서 `answers.count`와 같은 값으로 갱신하고, 둘이 다르면 `answers.count`를 따릅니다. 이미 답이 저장된 문제는 다시 채점하지 않습니다.
- 모든 문제의 답이 저장된 상태에서 종료됐다면, 복원할 때 문제 화면 없이 결과 계산(`finish`)부터 진행합니다.
- 피드백이나 애니메이션을 보던 도중에 종료됐다면, 다시 재생하지 않고 다음 문제로 이동합니다. 놓친 해설은 결과 화면의 오답 노트에서 볼 수 있습니다.
- 소요 시간(`elapsedSeconds`)은 퀴즈 화면이 떠 있고 앱이 활성 상태인 동안만 누적합니다. 답을 저장할 때와 앱이 백그라운드로 갈 때 저장하고, 이어 풀 때는 저장된 값에서 이어서 더합니다. 마지막 문제의 피드백·애니메이션을 보는 시간도 포함하며, `finish`가 마지막 누적값을 저장한 뒤 확정합니다. 앱이 강제 종료되면 마지막 저장 이후의 시간은 빠질 수 있습니다.
- 진행 중 세션이 있는데 사용자가 새 세션을 시작하려고 하면 "이어서 풀기"와 "새로 시작(기존 세션 버림)" 중 고르게 하고, 새로 시작을 고르면 확인 대화상자를 한 번 보여 준 뒤 기존 세션을 `abandoned`로 바꿉니다.
