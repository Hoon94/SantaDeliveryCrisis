## 문제 풀이 (S4, S5)
- 첨부 이미지는 세션 스냅샷의 파일명으로 로컬 미디어 저장소에서 읽어 문제 텍스트 아래에 표시합니다. 원본 비율과 색상을 유지하며 라이트·다크 모드에서 이미지를 반전하거나 색상막을 덮지 않습니다. 큰 이미지는 표시용으로 축소해 백그라운드에서 읽고, 로딩 또는 파일 누락·읽기 실패 상태를 안내합니다. 이미지 확대 보기는 제공하지 않습니다.
- 선택한 `장소 · 단계` 이름을 출제 지도와 동일하게 표시하며, 문항을 넘겨도 유지합니다. 단계 번호와 문항 진행에 따라 바뀌던 네 작업 과정 표시는 사용하지 않습니다. 장소·단계 이름은 [출제 화면 규칙](04-task-and-select.md#장소와-단계-이름)을 따릅니다.
- 보기 하나를 선택하고 **[확인]** 버튼을 눌러 채점합니다. 확인 전에는 선택을 바꿀 수 있습니다.
- 일반 문제: 확인 즉시 피드백을 표시합니다.
- 애니메이션 문제: 확인 후 애니메이션을 재생하고, 끝나면 정답 여부와 해설을 표시합니다. 건너뛰기와 다시 보기는 1차에 없습니다.
- 피드백
  - 정답: 초록색, ✓ 아이콘과 문구, 햅틱 `.success`, 효과음
  - 오답: 빨간색, ✕ 아이콘과 문구, 햅틱 `.error`, 보기 좌우 흔들림, 효과음
  - 색만으로 구분하지 않습니다.
- 같은 세션에 제목(문제 텍스트)이 같은 문제가 둘 이상 나오면 `[1/2]`처럼 이번 세션 안에서의 순서를 제목 앞에 붙입니다. 세션에 한 번만 나오는 제목에는 붙이지 않고, 세션 밖의 같은 제목은 세지 않습니다. 세션을 시작할 때 문제 복사본(스냅샷)의 제목에 붙이므로 결과와 오답 노트에도 같은 제목이 나옵니다.
- 답은 문제마다 저장됩니다(`02-session-engine.md` 이어서 풀기).

## 세션 결과 (S6)
- 보상 장식이 트리로 날아가는 연출은 이 화면에서 재생합니다. 문제별 연출에는 쓰지 않습니다.
- 오답이 있으면 오답 노트로 이동할 수 있고, 오답 문제의 학습 자료 링크를 "추천 학습 자료"로 모아서 보여 줍니다.
- 새 보상으로 트리가 완성되면 일반 장식 획득 화면에서 돌아가기를 누르고, 작업실 트리에 장식이 날아와 붙는 연출이 끝난 뒤 D1 「마을 위를 가로질러」 완성 연출을 재생합니다. 저장된 결과의 완성 여부를 사용하며, 연출에서 보상·트리 데이터를 다시 변경하지 않습니다.
- D1은 약 10초 동안 부착된 장식 → 별에 모인 빛 → 출발 인사 → 산타 마을 → 썰매 비행 → 배달 출발 순서로 진행합니다. 산타 대사는 “호호호! 크리스마스 선물을 전하러 출발하자!”, 마무리는 “크리스마스 선물 배달, 출발!”입니다.
- 작업실·마을 배경은 시스템 라이트·다크 모드를 따르고, 썰매는 `tree-completion-assets/sleigh-side.png`를 등록한 이미지 자산을 사용합니다. 비행은 4.4~8.6초이며 왼쪽에서 오른쪽으로 마을 위를 가로지릅니다.
- 연출 종료 또는 [건너뛰기] 후 배달 출발 문구와 [작업실로 돌아가기] 버튼을 표시합니다. 결과 카드는 다시 표시하지 않습니다. 동작 줄이기에서는 썰매가 있는 정지 완성 장면과 복귀 버튼을 바로 표시합니다. 실제 트리 완성 시 복귀 후 새 트리를 표시합니다.
- 앱이 비활성화되면 연출 시간과 피드백을 멈추고, 다시 활성화되면 남은 구간을 이어 갑니다. 새 보상이 없는 재풀이는 이 연출을 재생하지 않습니다.
- 개발 확인용으로 DEBUG 빌드의 `TreeCompletionConfiguration.startBeforeFinalStage`가 true이면 앱 시작마다 현재 트리를 지도 순서의 앞 열한 칸 획득 상태로 준비합니다. 마지막 「루돌프 정류장 · 출동 완료」를 통과하면 실제 트리 완성 조건으로 D1을 재생합니다. 기존 문제·풀이 기록은 유지하며 현재 트리의 보상 칸만 변경합니다. 일반 동작 확인 시 false로 되돌리며 Release 빌드에는 적용하지 않습니다.

## 작업별 보상과 재풀이 결과

세션의 장소·단계 이름은 저장된 `QuizSession.task`와 `difficulty`로 계산합니다. 문제의 카테고리 태그·배경·캐릭터 동작은 기존대로 유지합니다. 혼합 출제여도 보상 작업이 없어지는 것은 아닙니다. 결과와 장식 획득 안내에도 같은 장소·단계 이름을 사용합니다.

결과의 통과 여부는 `SessionResult.passedThreshold`, 새 장식 획득 여부는 `earnedDecorations`와 `rewardOutcome`으로 구분합니다. 이미 획득한 작업·난이도를 다시 통과한 경우 성공으로 표시하되 추가 보상과 획득·비행 연출은 없습니다. 기준 미달인 재풀이도 기존 보상은 유지됩니다. 모든 완료 세션은 기존 통계 기준에 포함합니다.
