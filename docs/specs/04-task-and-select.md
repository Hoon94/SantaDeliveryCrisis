## 출제 흐름

1. 작업실의 "퀴즈 시작하기"를 누르면 출제 탭(S2)으로 이동합니다 `[가정]`. 이전의 "4개 작업을 섞어서 구성하는 세션"은 1차에서 하지 않습니다([future-work](../future-work.md)).
2. 출제 탭에서 난이도, 카테고리(여러 개), 문제 수를 고르고 [장식 선택]을 누르면 S2-B로 넘어갑니다.
3. 켜진 장식을 누르면 S2에서 고른 카테고리 전체에서 문제를 고르게 섞어 세션을 시작합니다(`startSession(categories:...)`). 누른 장식은 문제 구성에 쓰지 않습니다. 카테고리를 하나만 골랐으면 `QuizSession.category`는 그 카테고리이고, 둘 이상이면 `nil`입니다(화면에는 "여러 카테고리 섞음"으로 표시). 어떤 장식을 눌렀는지가 보상으로 받는 장식에 영향을 주는지는 **미정**이며, 지금은 영향이 없습니다(보상은 장식 개수만 정해집니다).
4. 태그 선택은 1차에서 하지 않습니다. 모델과 인터페이스의 `tags`는 남겨 두고 항상 빈 집합을 넘깁니다.

## 문제 수와 장식 켜짐 조건

- 문제 수 5·10·15는 항상 선택할 수 있습니다. 잠금은 없습니다.
- 장식은 고른 카테고리 전체의 후보 수 합(`availableCount(categories:...)`, 고른 난이도 기준)이 고른 문제 수 이상일 때 켜집니다. 네 장식이 모두 같은 상태입니다. 카테고리별로 따로 따지지 않고, 고르지 않은 카테고리는 후보에 들어가지 않습니다.
- 후보 합이 고른 문제 수보다 적으면 네 장식이 모두 꺼지고 세션은 만들어지지 않습니다. 후보가 1개 이상이면 S2-B에 "고른 조건에는 N문제만 있어요" 안내를 보여 줍니다. 문제 수를 줄이거나 카테고리를 더 고르면 다시 켜집니다.
- 문제 구성: 문제 수를 고른 카테고리 수로 나눠 고르게 배정합니다(5문제 4카테고리는 2·1·1·1, 10문제 3카테고리는 4·3·3, 10문제 2카테고리는 5·5). 남는 문제는 무작위로 고른 카테고리에 한 문제씩 더 줍니다. 한 카테고리의 후보가 모자라면 다른 카테고리의 남은 후보로 채우고, 중복 출제는 없습니다. 카테고리 안의 선택은 [02-session-engine](02-session-engine.md)의 범주 규칙을 따릅니다.
- 진행 중 세션이 있을 때 켜진 장식을 누르면 [02-session-engine](02-session-engine.md)의 이어서 풀기 규칙을 그대로 적용합니다. 이어서 풀기를 고르면 기존 세션을 쓰고 팝업의 설정을 덮어쓰지 않습니다.

## 카테고리 추천 배지 `[가정]`

- 답을 한 기록이 있는 카테고리 중 정답률이 가장 낮은 카테고리 하나에 [추천] 배지를 붙입니다. 카테고리는 답한 문제의 스냅샷(`QuestionSnapshot.category`) 기준입니다.
- 정답률이 같으면 작업 순서(소원 접수, 선물 생산, 포장, 썰매 적재)에서 앞선 카테고리를 추천합니다. 기록이 전혀 없으면 배지를 붙이지 않습니다.
- 계산은 작업 2의 `TaskRecommending`이 하고, 이 화면은 결과만 표시합니다.

## 팝업 상태 정리 `[가정]`

- 카테고리는 최소 1개를 유지합니다(마지막 하나는 해제할 수 없음).
- 팝업을 취소하면 이전에 적용한 설정을 유지하고, 처음 들어와서 취소하면 기본값(보통·카테고리 4개·5문제)을 적용합니다.

## 1차에서 하지 않는 것

- 장식 위 난이도 통과 점, 문 열림 문구, 초기화 버튼: 시안 v3의 규칙이며 확정 규칙(12칸 한 그루, 세션 정답률 기준)과 달라 넣지 않습니다.
- 설계서(`screen-spec.html`)와 디자인 매뉴얼의 S2-B 예시 그림에 있는 장식 아래 통과 점과 ✓, 그리고 S2-A3·S2-A4 알림은 오래전에 만든 시안(v3)의 규칙입니다. 개발하면서 팀이 합의한 규칙(장식은 카테고리와 연동하지 않음)과 다르므로 **예시 그림은 무시합니다.** 통과 점은 1차에 만들지 않으므로, 카테고리를 여러 개 고른 세션(`category == nil`)을 어느 카테고리의 통과로 셀지는 1차에 정할 필요가 없습니다. 카테고리별 통계(취약 카테고리 등)는 답한 문제의 스냅샷 `category`로 집계하므로 이런 세션도 문제별 카테고리에 반영됩니다.
- 태그 선택, 문제 수 잠금, 작업실의 별도 "오늘의 출제" 혼합 세션(카테고리를 여러 개 골라 섞어 출제하는 것은 합니다).

## 연출

- **장식→퀴즈 전환** `[가정]`: 켜진 장식을 누르면 장식 위치에서 퀴즈 화면이 커지며 열리는 연출을 씁니다. `navigationTransition(.zoom)`은 iOS 18부터라 iOS 17에서는 직접 구현해야 하므로, 1차는 페이드로 시작하고 여유가 있으면 확대 연출로 올립니다. 모션 줄이기가 켜져 있으면 항상 페이드입니다.
- **색** `[가정]`: 출제 탭(S2, S2-B와 그 위의 시트·알림)만 나이트 글로우 팔레트(하늘색 그라데이션 배경, 다크는 남색)를 씁니다. 탭을 오갈 때 색이 바뀌므로 최종 색을 하나로 할지는 팀이 정해야 합니다. 색은 Asset 색상 세트로만 정의합니다.
