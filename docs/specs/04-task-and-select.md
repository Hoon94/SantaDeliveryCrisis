- 담당: **C** ([팀 업무 분담](../team-work-assignment.md))
- 상위 문서: [프로젝트 스펙](../../.kiro/steering/project-spec.md). 이 문서에서 말하는 5장, 8장, 9장, 11장은 그 문서의 장입니다. 데이터 모델(8장)과 모듈 인터페이스(9장)는 모든 작업이 맞춰야 하는 공통 계약이라 그쪽에 있습니다.

## 출제 흐름

1. 작업실의 "퀴즈 시작하기"를 누르면 출제 탭(S2)으로 이동합니다 `[가정]`. 이전의 "4개 작업을 섞어서 구성하는 세션"은 1차에서 하지 않습니다([future-work](../future-work.md)).
2. 출제 탭에서 해금된 난이도, 카테고리(여러 개), 문제 수를 고르고 [스테이지 선택]을 누릅니다. 다음 미획득 단계가 해당 난이도이면 그 단계, 아니면 해당 난이도의 첫 획득 단계로 지도가 이동합니다.
3. 열린 단계를 누르면 단계에 대응하는 `task`와 `difficulty`를 `startSession(task:categories:...)`로 전달합니다. 카테고리·문제 수는 유지하고 선택 단계에 난이도를 맞춥니다. 저장 형식과 작업·난이도별 중복 보상 방지는 그대로이며 재도전은 기존 확인 후 허용합니다.
4. 태그 선택은 1차에서 하지 않습니다. 모델과 인터페이스의 `tags`는 남겨 두고 항상 빈 집합을 넘깁니다.

### 작업과 문제 카테고리의 화면 표시

- 문제 위에는 선택한 장소·단계 이름, 난이도, 현재 문제의 카테고리를 함께 표시합니다. 장소·단계 이름은 문항 진행과 무관하게 세션 동안 유지합니다.
- 퀴즈 배경·캐릭터의 기존 문항 진행에 따른 변화는 유지합니다. 네 작업 과정의 진행 표시와 결과 배경의 옛 작업명은 표시하지 않습니다.
- 출제의 이어 풀기 시트와 작업실·퀴즈·결과는 저장된 작업·난이도로 `장소 · 단계` 이름을 표시합니다. 결과 장식 색은 기존처럼 `QuizSession.task`를 따릅니다. 혼합 문제 카테고리의 표기는 별도로 "여러 카테고리 섞음"을 사용합니다.
- 카테고리별 통계는 답한 문제의 스냅샷 `category`로 집계하므로 혼합 세션도 각 문제의 카테고리에 반영됩니다.

### 장소와 단계 이름

지도 구역에는 장소 이름과 난이도, 지점에는 단계 이름만 표시합니다. 단계 번호는 화면과 접근성 설명에 표시하지 않습니다. 저장 식별자와 해금 순서는 유지합니다.

| 난이도 | 장소 | 단계 순서 |
| --- | --- | --- |
| 쉬움 | 소원 우체국 | 우편함 열기 → 주소 확인 → 소원 기록 → 접수 마감 |
| 보통 | 선물 제작소 | 재료 준비 → 뚝딱 조립 → 리본 포장 → 품질 검사 |
| 어려움 | 루돌프 정류장 | 썰매 점검 → 선물 싣기 → 루돌프 정렬 → 출동 완료 |

## 문제 수와 단계 시작 조건

- 문제 수 5·10·15는 항상 선택할 수 있습니다. 잠금은 없습니다.
- 각 단계의 출제 후보는 해당 난이도와 선택 카테고리 전체의 후보 합으로 계산합니다. 순차 해금과 후보 충분 여부는 별개입니다. 잠긴 단계는 선행 획득 안내, 열린 단계의 후보 부족은 문제 수·카테고리 변경 안내를 표시합니다. 후보 부족으로 보상·해금 기록을 변경하지 않습니다.
- 후보 합이 고른 문제 수보다 적으면 열린 단계도 새로 시작할 수 없습니다. 후보 0개를 포함해 "고른 조건에는 N문제만 있어요" 안내를 표시합니다. 문제 수·카테고리를 바꿔 후보를 확보할 수 있으며, 기존 진행 중 세션의 이어 풀기는 유지합니다.
- 문제 구성: 문제 수를 고른 카테고리 수로 나눠 고르게 배정합니다(5문제 4카테고리는 2·1·1·1, 10문제 3카테고리는 4·3·3, 10문제 2카테고리는 5·5). 남는 문제는 무작위로 고른 카테고리에 한 문제씩 더 줍니다. 한 카테고리의 후보가 모자라면 다른 카테고리의 남은 후보로 채우고, 중복 출제는 없습니다. 카테고리 안의 선택은 [02-session-engine](02-session-engine.md)의 범주 규칙을 따릅니다.
- 진행 중 세션이 있을 때 열린 단계를 누르면 [02-session-engine](02-session-engine.md)의 이어서 풀기 규칙을 그대로 적용합니다. 이어서 풀기를 고르면 기존 세션을 쓰고 팝업의 설정을 덮어쓰지 않습니다.

## 카테고리 추천 배지 `[가정]`

- 답을 한 기록이 있는 카테고리 중 정답률이 가장 낮은 카테고리 하나에 [추천] 배지를 붙입니다. 카테고리는 답한 문제의 스냅샷(`QuestionSnapshot.category`) 기준입니다.
- 정답률이 같으면 작업 순서(소원 접수, 선물 생산, 포장, 썰매 적재)에서 앞선 카테고리를 추천합니다. 기록이 전혀 없으면 배지를 붙이지 않습니다.
- 계산은 작업 2의 `TaskRecommending`이 하고, 이 화면은 결과만 표시합니다.

## 팝업 상태 정리 `[가정]`

- 카테고리는 최소 1개를 유지합니다(마지막 하나는 해제할 수 없음).
- 팝업 취소는 이전 적용값을 유지합니다. 첫 진입·초기화·새 세션 생성 성공 후 기본값은 다음 도전 단계의 난이도, 전체 카테고리, 5문제입니다. 이어 풀기와 시작 실패에서는 기존 출제 조건을 유지합니다.

## 1차에서 하지 않는 것

- 트리·보상 기록 삭제 초기화와 필터 단계의 모든 카테고리 통과 알림(S2-A4)은 넣지 않습니다. 초기화 버튼은 출제 조건만 초기화합니다.
- 태그 선택, 문제 수 잠금, 작업실의 별도 "오늘의 출제" 혼합 세션(카테고리를 여러 개 골라 섞어 출제하는 것은 합니다).

## 연출

- 스테이지에서 퀴즈로 진입할 때 기존 전체 화면 페이드를 유지합니다. 지도 위 눈·구슬·화살표는 화면 표시·앱 활성·다른 화면에 가려짐 여부를 따르며 동작 줄이기에서는 정지합니다.
- **색** `[가정]`: 출제 탭(S2, S2-B와 그 위의 시트·알림)만 나이트 글로우 팔레트(하늘색 그라데이션 배경, 다크는 남색)를 씁니다. 탭을 오갈 때 색이 바뀌므로 최종 색을 하나로 할지는 팀이 정해야 합니다. 색은 Asset 색상 세트로만 정의합니다.

## 재풀이와 보상 표시

- 기존 세 난이도 인디케이터를 별도로 표시하지 않고 열두 지점의 보상 구슬과 완료 체크로 대체합니다. 출제 화면은 위 장소와 단계 이름을 사용합니다.
- 난이도 선택의 기존 색상과 카드 디자인은 유지하고 잠금 상태를 기호·접근성 설명으로 함께 전달합니다.
- 기존 세션이 있으면 이어 풀기·새로 시작 선택 및 기존 재시작 확인을 먼저 거칩니다. 재풀이 확인까지 동의한 뒤에만 `abandon` → 새 세션 생성을 실행합니다. 취소하면 기존 세션을 보존합니다.
- 결과는 기준 통과 여부와 새 보상 여부를 분리합니다. 새 보상이 있을 때만 획득·비행 연출을 실행합니다.
- 작업실 트리는 기존처럼 장식 총개수만큼 순서대로 채웁니다. 다음 트리에서는 같은 작업·난이도로 다시 보상을 받을 수 있습니다.

## 스테이지 순차 해금 (최신 사용자 결정)

- `QuizStage.all`은 쉬움·보통·어려움 순서이며 각 난이도에서는 소원 접수·선물 생산·포장·썰매 적재의 기존 저장 식별자를 1~4단계에 대응합니다. 화면 이름과 내부 보상 식별자는 분리합니다.
- `1-1 → 1-2 → … → 3-4` 순서로 진행합니다. 기준 정답률 이상으로 장식을 받아야 다음 미획득 단계가 열립니다. 단순 세션 완료나 기준 미달은 다음 단계의 해금 조건이 아닙니다.
- 해금은 `TreeRecord.rewardMask`로 계산합니다. 별도 저장값은 없으며 개수만으로 단계를 추정하지 않습니다. 첫 미획득 단계와 이미 획득한 단계만 새로 시작할 수 있습니다.
- 변경 이전의 비순차 보상은 모두 보존하고 재도전도 허용합니다. 중간 빈칸 중 가장 앞선 단계를 다음 도전으로 삼습니다. 기존 진행 중 세션의 복원·채점·완료에는 신규 해금 제한을 적용하지 않습니다.
- 다음 난이도의 첫 미획득 단계 또는 해당 난이도의 기존 획득 칸이 있어야 설정에서 그 난이도를 선택할 수 있습니다. 난이도 선택은 지도 위치 이동과 연동합니다.
- 12개 획득 후 새 트리가 생성되면 `1-1`부터 다시 시작합니다. 데이터 삭제·초기화·마이그레이션은 없습니다.
- 큰 글자 접근성 크기에서는 열두 단계를 목록으로 표시합니다. 지도 지점의 터치 영역은 44pt 이상이며 완료·잠금·난이도·보상을 읽어 줍니다.
- 디자인 HTML의 비교 도구와 오른쪽 상세 카드는 앱에 추가하지 않습니다. 퀴즈 안의 작업 과정 테마 변경과 새 보상 모양은 이번 변경에 포함하지 않습니다.

### 지도 조작과 잠금 표시 보정

- 난이도 카드는 이름 아래의 상태 줄에 자물쇠와 `잠김`을 표시합니다. 열린 난이도도 같은 줄에 선택 상태를 표시해 카드 높이를 맞춥니다.
- 지도 단계 이름은 줄바꿈을 허용하며, 잠금 아이콘은 이름표가 아닌 발판 위에 배치합니다. 구슬과 발판은 각각 같은 단계에 진입하는 터치 영역입니다.
- 지도 전용 스크롤 컨테이너는 콘텐츠 끝에서 바운스 없이 멈춥니다. 프로그램으로 현재 단계에 이동할 때도 오프셋을 `0...콘텐츠 폭-화면 폭` 안으로 제한합니다. 기존 배경 이미지와 단계 좌표는 유지합니다.
