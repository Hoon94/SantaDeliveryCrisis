# 작업 4. 작업실·출제 화면

- 상위 문서: [프로젝트 스펙](../../.kiro/steering/project-spec.md). 이 문서에서 말하는 5장, 8장, 9장, 11장은 그 문서의 장입니다. 데이터 모델(8장)과 모듈 인터페이스(9장)는 모든 작업이 맞춰야 하는 공통 계약이라 그쪽에 있습니다.
- 통합 완료 조건과 확인 담당: [통합 계약표](../integration-contracts.md)
- 표기: `[가정]`은 팀이 아직 확정하지 않은 내용입니다. 구현 전에 사용자에게 확인합니다(프로젝트 스펙 16장).

## 작업 범위

- 포함: S1, S2, S3a/S3b(카테고리·태그 선택 포함), 트리 렌더링, 장식 켜짐/꺼짐, 완성 연출
- 의존: 0, 2의 프로토콜
- 병렬 가능: -

## 담당 화면

| ID | 화면 | 위치 | 설명 |
| --- | --- | --- | --- |
| S1 | 작업실 메인 | 작업실 탭 루트 | 트리와 장식 진행도(n/12), 난이도별 "남은 문제"(아직 한 번도 풀지 않은 문제 수 / 전체 문제 수, 4개 작업 합계), "문제 풀기" 버튼. 진행 중 세션이 있으면 버튼이 "이어서 풀기"로 바뀝니다 `[가정]`. "문제 풀기"를 누르면 S3 팝업이 열리고, 난이도 카드를 눌러도 해당 난이도를 미리 고른 S3가 열립니다 `[가정]` |
| S2 | 출제 화면 | 출제 탭 루트 | 큰 트리와 4개 카테고리 장식(AI 활용/소원 접수, Swift 문법/선물 생산, HIG/포장, SwiftUI 실전/썰매 적재). 장식은 **켜짐**(고른 카테고리이고 선택한 난이도·태그·문제 수의 후보가 충분함) 또는 **꺼짐**(그 외). 켜진 장식을 누르면 그 카테고리 하나의 세션이 시작됩니다. 상단에 설정 요약 칩(예: "보통 · 카테고리 4개 · 5문제")이 있고 누르면 S3b가 다시 열립니다. 처음 들어오면 S3b를 먼저 보여 줍니다 |
| S3 | 출제 설정 팝업 | 팝업 | 두 종류입니다. **S3a(작업실)**: 난이도(쉬움/보통/어려움)와 문제 수(5/10/15)만 고르고, "취약한 주제를 섞어서 구성해요" 안내를 보여 줍니다. **S3b(출제 탭)**: 난이도(별 1~3개), 카테고리 다중 선택(기본 4개 모두), 태그 칩(선택한 카테고리의 태그 합집합, 기본 "전체", 여러 개면 하나라도 가진 문제), 문제 수(5/10/15), 요약 한 줄, "트리에서 장식 고르기" 버튼. 후보 문제 수가 선택한 문제 수보다 적으면 그 문제 수는 비활성화하고 "문제가 더 추가되면 열려요" 안내를 표시 (`04-task-and-select.md` 참고) |

## 문제 수 선택과 장식 켜짐 조건
- 문제 수 선택지(5, 10, 15)는 후보 문제 수가 선택지 이상일 때만 활성화합니다. 조건은 `사용 가능한 문제 수 >= 선택지`입니다.
  - 오늘의 출제(S3a): 선택한 난이도의 4개 작업 전체 문제
  - 출제 탭(S3b): 선택한 카테고리 중 **적어도 하나**의 후보 수(`availableCount`, 선택한 난이도·태그 기준)가 선택지 이상일 때 활성화합니다. 장식 하나가 카테고리 하나의 세션을 시작하므로, 합계로 열면 모든 장식이 꺼지는 설정이 생기기 때문입니다.
  - 태그나 카테고리를 바꾸면 즉시 다시 계산합니다.
  - S3b 상태 정리 `[가정]`: ① 카테고리는 최소 1개를 유지합니다(마지막 하나는 해제할 수 없음). ② 카테고리를 바꾸면 선택한 태그 중 새 태그 합집합에 없는 것은 선택에서 뺍니다. ③ "전체" 칩과 개별 태그는 동시에 선택하지 않습니다(개별 태그를 모두 해제하면 "전체"). ④ 선택한 문제 수가 무효가 되면 활성화된 가장 큰 문제 수로 바꾸고, 활성화된 문제 수가 없으면 완료 버튼을 비활성화합니다. ⑤ 팝업을 취소하면 이전에 적용한 설정을 유지하고, 처음 들어와서 취소하면 기본 설정(보통·카테고리 4개·전체 태그·5문제)을 적용합니다.
- S2의 장식은 카테고리별로 `availableCount(그 카테고리, 난이도, 태그) >= 선택한 문제 수`이고 그 카테고리를 골랐을 때만 켜집니다. 아니면 꺼집니다. 위 S3b 규칙 덕분에 켜진 장식이 하나 이상 있는 상태에서만 S3b를 완료할 수 있습니다.
- 진행 중 세션이 있을 때 켜진 장식을 누르면 [02-session-engine](02-session-engine.md)의 이어서 풀기 규칙(이어서 풀기 / 새로 시작 확인 후 기존 세션 `abandoned`)을 그대로 적용합니다. 이어서 풀기를 고르면 기존 세션을 쓰고 S3b의 설정을 덮어쓰지 않습니다.
- 1차에는 구간(작업 × 난이도)당 시드가 5문제입니다. 그래서 선택 출제는 **5문제만 켜지고**, 오늘의 출제는 난이도당 후보가 20문제(5×4작업)라서 5·10·15가 모두 활성화됩니다. 실제 활성화는 항상 `availableCount` 결과를 따릅니다.
- 문제가 추가되면(시드를 늘리거나 사용자가 만들면) 코드를 바꾸지 않아도 선택지가 자동으로 활성화됩니다.
- **장식→퀴즈 전환 연출** `[가정]`: 켜진 장식을 누르면 장식 위치에서 퀴즈 화면이 커지며 열리는 연출을 씁니다. `navigationTransition(.zoom)`은 iOS 18부터라 iOS 17에서는 직접 구현해야 하므로, 1차는 페이드로 시작하고 여유가 있으면 확대 연출로 올립니다. 모션 줄이기가 켜져 있으면 항상 페이드입니다.
