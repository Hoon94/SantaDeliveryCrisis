## 기록 대시보드 (S9)
- 주/월 전환 세그먼트
- 표시: 퀴즈 시도 횟수, 평균 점수, 풀이 문제 수 막대 차트, 평균 점수 추이 선 차트, 취약 카테고리 (정답률 낮은 순)
- 완성한 트리: 요약 카드에 완성한 트리 수를 숫자로 보여 줍니다(`TreeManaging.completedTrees().count`). 보관함 화면은 1차에 없습니다([future-work](../future-work.md)). 데이터는 계속 저장합니다.
- 집계 기준
  - 시도 횟수: 끝낸(`completed`) 세션 수. 중간에 그만둔(`abandoned`) 세션과 진행 중 세션은 제외
  - 평균 점수: 세션별 정답률(%)의 평균을 반올림한 정수
  - 기간: 주간은 월요일 시작(월요일로 고정), 월간은 그 달 1일 시작. 세션이 끝난 시각(`finishedAt`) 기준
  - 소요 시간: `elapsedSeconds`

## 설정 (S12)

| 키 (@AppStorage) | 타입 | 기본값 | 설명 |
| --- | --- | --- | --- |
| `hasLaunchedBefore` | Bool | false | 첫 실행 여부 (시드 주입과 온보딩 판단) |
| `passThresholdPercent` | Int | 80 | 보상 받는 정답률 기준 (50~100, 10 단위) |
| `soundEnabled` | Bool | true | 효과음 |
| `hapticsEnabled` | Bool | true | 진동 |

- 테마는 시스템 설정(라이트/다크)을 따릅니다. 앱 안에 테마 선택 설정은 없습니다.
- 글자 크기는 시스템 설정(Dynamic Type)을 따르고 앱 안에 별도 글꼴 크기 설정은 두지 않습니다. 과제의 "사용자 설정에 따라 폰트 크기 업데이트" 요구는 시스템 설정을 따르는 것으로 충족한다고 해석하며, 이 해석은 README에 설명합니다.
