# 작업 8. 에셋·사운드

- 상위 문서: [프로젝트 스펙](../../.kiro/steering/project-spec.md). 이 문서에서 말하는 5장, 8장, 9장, 11장은 그 문서의 장입니다. 데이터 모델(8장)과 모듈 인터페이스(9장)는 모든 작업이 맞춰야 하는 공통 계약이라 그쪽에 있습니다.
- 통합 완료 조건과 확인 담당: [통합 계약표](../integration-contracts.md)
- 디자인 기준: [디자인 매뉴얼](../design/santa-workshop-main-manual.html) 5장(디자인 토큰). 출제 탭만 나이트 글로우 팔레트를 쓰므로 그 색 세트도 Asset에 추가합니다 `[가정]`
- 표기: `[가정]`은 팀이 아직 확정하지 않은 내용입니다. 구현 전에 사용자에게 확인합니다(프로젝트 스펙 16장).

## 작업 범위

- 포함: 캐릭터, 트리, 장식, 배경, 효과음, 앱 아이콘
- 의존: 없음
- 병렬 가능: 처음부터 병렬

## 에셋 목록

| 에셋 | 형식 | 담당 | 비고 |
| --- | --- | --- | --- |
| 산타, 루돌프, 장면 캐릭터 | PNG 또는 PDF 벡터 | 팀 내 지정 | 애니메이션 장면용 |
| 트리, 장식 12종, 배경 | PNG 또는 PDF 벡터 | 팀 내 지정 | 장식 위치 좌표는 8장 모델이 아닌 뷰 코드에서 관리 |
| 효과음(정답, 오답, 완성) | wav 또는 m4a | 팀이 직접 제작 | 저작권 문제가 없는 소스만 사용 |
| 앱 아이콘 | 1024px | 팀 내 지정 | |

색상은 라이트/다크 모두 Asset 카탈로그에 정의합니다.
